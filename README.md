# 股票帳本

記錄台股買賣、定期定額和股利，並自動算出：**如果同一天、同樣的錢改買 0050／0056／00646，現在會是多少**。

- 用手機 Safari 打開網址 →「分享」→「加入主畫面」，就像 App 一樣使用。
- 每個人的紀錄只存在自己手機的瀏覽器裡，不會上傳，別人看不到。請定期用「匯出備份」。
- 股價每個交易日收盤後（台灣時間約 15:30）由 GitHub Actions 自動更新。

## 怎麼算的

每次買進，就假設同一天把同樣金額（含手續費）買進比較用的 ETF；賣出或領股利時，ETF 那邊也同一天拿回同樣的錢。兩邊投入與拿回的現金完全相同，只差在買了什麼。ETF 用含息價格，等於配息都再投入（00646 不配息）。

## 資料來源

- 證交所 OpenAPI：上市股票與 ETF 每日收盤價
- 櫃買中心 OpenAPI：上櫃股票每日收盤價
- Yahoo Finance（yfinance）：0050、0056、00646 的含息歷史價格

美股、興櫃等沒有自動價格，可在持股裡手動輸入。

## 第一次設定（只要做一次）

1. 在 GitHub 建立**公開**專案並推送這些檔案。
2. 專案的 Settings → Pages → Build and deployment → Source 選 **GitHub Actions**。
3. 到 Actions 分頁，手動執行一次「更新股價並發布」。完成後網址是 `https://<帳號>.github.io/<專案名>/`。

本工具只做記帳與比較，不構成投資建議。
